# 포켓몬 모드 — 남은 일

> 2026-11-05 회사 PC에서 넘겨받은 화면 개편(메인 · 풀숲 만남 · 가방 · 체육관 · 교환 · 훈장)과 방향키 쌓임 수정은 끝났다(개인 PC,
> working_place PR #15~#22). 배틀 화면 원작 배치(PR #25)와 배틀 타워 추천이 지난 판 것으로 남던 버그(PR #26·#27)도 끝. 아래는 남은 확인. 하나씩 끝내면 이 파일에서 지운다.
>
> 화면을 바꿀 때 사용자 방식: 패널 그림(번호 붙인 상자)이나 고를 수 있는 배치안을 주면 그 비율대로 배치한다. 그림과 다르면 바로
> 지적하니 비율을 꼼꼼히 맞출 것. 도감 화면은 사용자가 "일단 건드리지 말자"로 정했다가, 2026-11-11 사용자 요청으로 못 본 포켓몬 실루엣만 더함(PR #44) — 그 밖은 요청이 있을 때만.

## 1. 실제 화면에서 눈으로 확인할 것
- 메인·만남 화면은 패널 크기에 맞춰 그림 크기를 정한다(team_layout · big_art, PR #15). 가상 터미널로 배치는 확인했지만 그림 자체는
  못 봤다 — 개인 PC(cmux, Kitty 그래픽)에서 그림이 칸을 넘거나 이름과 겹치면 `mon_art`·`big_art` 를 본다.
- 만남 화면 그림 크기 보정 `SIXEL_SCALE = 1.6` 은 회사 PC(Windows Terminal + tmux) 스크린샷 한 장으로 잰 값. Kitty 는 보정 없이 칸 수 그대로.
- 합체 도구로 실제 합체까지 해 본 적 없음(시험으로만).
- 배틀 화면은 원작 배치로 바꿨다(상대 상자·그림 위, 내 그림(좌우 뒤집음)·상자 아래, 대사 상자, PR #25). 가상 터미널(22×62·30×100·14×44)로
  배치와 Kitty 그림 자리는 확인했지만 그림 자체는 못 봤다 — 실제 화면에서 그림이 상자와 겹치거나 너무 크면 `fight` 화면의 `rows_`·`x0/x1` 을 본다.
  내 쪽은 진짜 뒷모습이 아니라 앞모습을 뒤집은 것(뒷모습 그림이 없는 세대가 있어서) — 뒷모습을 원하면 PokeAPI `back/` 을 받고 없을 때만 뒤집기.
- 배틀 화면의 내 이로치 포켓몬은 이로치 그림(2026-11-09, `battle_now['shiny']`) — 시험으로만, 실제 배틀 화면은 못 봄.
- 세대 훈장(빛나는 부적 + 금색 로마 숫자, `_pokedata.charm_numeral`)이 장식 줄·훈장 화면 크기에서 숫자가 읽히는지 —
  확대 미리보기로만 봤다. 뭉개지면 숫자를 굵게 하거나 테두리를 뺀다.
- 포켓몬 상세 화면(팀 자리 고르기 → i, PR #39)의 리본·증표 그림 — 가상 터미널로 두 줄 배치(8개, 40칸×6줄)는 봤다. 실제 화면에서
  작거나 칸을 넘으면 `view == 'mon'` 의 `per`(한 줄 개수)·`rows_` 를 본다.
- 닉네임 한글 입력 — ③ 에 들어가면 영문 자판으로 바뀐다(macism, 단축키 두 번 눌림 방지). 한글 이름은 입력 중에 자판을 직접 바꿔야
  할 수 있다 — 불편하면 이름 짓는 동안만 원래 자판으로 되돌리기(`input-source.saved`).
- 도감 실루엣 색(`_pokedata.SILHOUETTE` = 어두운 회색 88·92·104, PR #44) — 가상 터미널로 놓이는 자리만 봤다. 실제 화면에서
  바탕에 묻히면 밝게, 너무 튀면 어둡게 바꾼다(회색 설정 `c` 일 때도 같은 색).
- 체육관 목록 아래 배지(2026-11-11): 뒤에서 만들어 몇 초 뒤 나타나고 `sprites/strips/` 에 남는다 · Sixel 에선 `SIXEL_SCALE` 로
  줄여 고른다(회사 PC 에서 화면 아래를 넘던 것) — 실제 Sixel 화면에선 못 봤다. Kitty(개인 PC)는 보정이 없어 예전 크기 그대로.

## 개인 PC 저장을 처음 열 때 바뀌는 것 (2026-11-06~09 회사 PC 변경) — 열어 보고 이상 없으면 이 절을 지운다
- 개체값이 셋 → 여섯(HP·공·방·특공·특방·스피드)으로 옮겨진다: 옛 [공, 방, 체] 는 HP·공·방으로, 특공·특방·스피드는 새로 뽑는다
  (전설·알 바닥 10 · 우두머리 12). 100% ★ 는 대부분 빠지는 게 정상. 목록은 % 만, 여섯 값은 목록 아래 줄·특훈 화면에.
- 진화로만 얻는 종의 연구 잡기 목표가 1이 되어, 조건을 채운 종은 그때 연구 완료 — 슈퍼볼·메가스톤이 한꺼번에 들어온다
  (회사 PC 저장은 14종 · 슈퍼볼 28 · 메가스톤 10). 소식 줄에 연구 완료가 여러 개 뜨는 게 정상.
- 세대 열림 조건이 "챔피언 + 그 세대 야생 종(전설·환상 포함) 전부"로 바뀌어(2026-11-09), 챔피언만 이기고 넘어간 세대가 있으면 그
  세대로 돌아간다 — 소식 "N세대 야생 포켓몬 k종을 마저 잡으면 …"이 한 번 뜨고, 탐색이 남은 종으로 몰려 금방 다시 열리는 게 정상
  (회사 PC 는 2세대 전설·환상 4종 → 3세대가 잠시 닫힘).

## 밸런스 지켜볼 것
- 앞 세대 전설·환상은 섞기 탐색에서 한 종마다 0.88%, 전체 최대 60%로 고정했다(2026-11-09, `OLD_LEGEND_EACH`·`OLD_LEGEND_CAP`).
  처음엔 가중치 10배였는데 1세대처럼 후보가 적을 때 같은 전설이 섞기 넷 중 하나로 나와서(파이어가 잡은 뒤에도 연달아) 바꿨다.
  값은 그 10배가 8세대에서 내던 몫이라 후반은 그대로 — 8세대쯤 탐색의 약 12%(하루 4마리)가 전설이라 하이퍼볼이 모자랄 수 있다.
  전설은 하이퍼볼·마스터볼로만, 만남마다 2개쯤. 모자라면 하이퍼볼 얻는 길을 늘리거나 OLD_LEGEND_CAP 을 낮춘다.
- 서식지(h, PR #39)는 고른 타입만 나오게 해 세대 마지막 몇 종을 빨리 채운다 — 도감이 너무 쉽게 차면 서식지를 고른 탐색에만
  작은 비용(예: 볼 1개)을 붙이거나, 지금 세대 창(WINDOW) 밖 종은 그대로 드물게 두는 쪽을 본다.
- 일한 보상을 볼에서 탐색으로 바꿨다(2026-11-11, PR #41·#42): 평일 +1 · 주말 부스트 +2 · 연속 5일째마다 +5. 전에 있던
  하루 슈퍼볼 1개·3일 연속 하이퍼볼이 빠져 하이퍼볼은 주간 과제·체육관 첫 승·타워 21연승·연구·알에서만 들어온다.
  전설을 잡다 하이퍼볼이 모자라면 연속 보상 일부를 하이퍼볼로 되돌리거나, 탐색이 너무 빨리 쌓이면 STREAK_BONUS 를 줄인다.
